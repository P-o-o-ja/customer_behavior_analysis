# Customer Shopping Behavior Analysis

## Project Overview

This project is an end-to-end **Customer Shopping Behavior Analysis** using **Python, MySQL, SQL, and Power BI**.

The objective of this project is to analyze customer purchasing behavior, product preferences, spending patterns, subscription behavior, and customer segments to generate meaningful business insights and recommendations.

The project follows a complete data analytics workflow:

**Python → MySQL → SQL → Power BI → Business Insights**

---

## Business Problem

Understanding customer shopping behavior helps businesses improve customer engagement, increase sales, strengthen customer loyalty, and optimize marketing strategies.

This project analyzes customer transaction data to answer key business questions such as:

- Which customer groups generate the most revenue?
- Which products perform the best?
- Do subscribed customers spend more than non-subscribers?
- How do discounts affect purchasing behavior?
- Which customers are new, returning, or loyal?
- Which products receive the highest ratings?
- How does purchasing behavior vary across age groups?
- Which shipping methods are preferred by customers?

---

## Dataset

The dataset contains **3,900 customer purchase records** and **18 columns**.

### Customer Demographics
- Age
- Gender
- Location
- Subscription Status

### Purchase Details
- Item Purchased
- Category
- Purchase Amount
- Season
- Size
- Color

### Shopping Behavior
- Discount Applied
- Promo Code Used
- Previous Purchases
- Frequency of Purchases
- Review Rating
- Shipping Type

The dataset contains **37 missing values in the Review Rating column**, which are handled during the data-cleaning process.

## Project Workflow

### 1. Python – Data Cleaning & Exploratory Data Analysis

Python and Pandas were used to prepare the raw dataset for further analysis.

Key activities included:

- Loading and inspecting the dataset
- Checking data types
- Identifying missing values
- Handling missing Review Rating values
- Renaming columns for consistency
- Creating additional features
- Checking duplicate and redundant columns
- Performing exploratory data analysis
- Preparing the cleaned dataset for MySQL

---

### 2. MySQL – Database Integration

The cleaned dataset was loaded into **MySQL** for structured storage and SQL-based analysis.

Key activities included:

- Creating the database and table
- Connecting Python with MySQL
- Loading the cleaned dataset into MySQL
- Verifying the imported data
- Running SQL queries for business analysis

---

### 3. SQL – Business Analysis

SQL was used to answer important business questions related to customer behavior, product performance, and revenue.

### Business Questions

1. What is the revenue generated by each gender?

2. Which customers are high spenders and also use discounts?

3. What are the top 5 products based on customer ratings?

4. How does purchasing behavior vary across different shipping types?

5. How do subscribers compare with non-subscribers?

6. Which products are most dependent on discounts?

7. How can customers be segmented into New, Returning, and Loyal customers?

8. What are the top 3 products in each category?

9. How many repeat buyers are subscribers?

10. How does revenue vary across different age groups?

## Business Recommendations

### 1. Boost Subscription Adoption

Encourage non-subscribers to join subscription programs by providing exclusive offers, discounts, and other benefits.

Introduce loyalty programs and targeted rewards for returning and loyal customers.

### 3. Review Discount Strategy

Analyze discount-dependent products and optimize discount strategies while maintaining profitability.

### 4. Improve Product Positioning

Focus marketing efforts on high-performing and highly rated products.

### 5. Targeted Marketing

Use customer demographics, purchasing behavior, and customer segments to create targeted marketing campaigns.
